# Annonces

Cartes interactives de l'immobilier dans le Grand Nancy (12 communes), publiées via GitHub Pages.

- `index.html` : page d'accueil, une ligne par date de récupération des données (la plus récente en haut) ;
- `AAAA-MM-JJ/appartements.html` : appartements à vendre en dernier étage (plus de 69 m², 500 000 € maximum, ascenseur et stationnement) ;
- `AAAA-MM-JJ/programmes.html` : programmes neufs en vente, rattachés aux permis Sitadel ;
- `appartements.html`, `programmes.html` : copies de la version la plus récente.

Versions : 10/11/2026 (annonces Bien'ici, Leboncoin, SeLoger, PAP et Immobilier des notaires ; SeLoger Neuf et Plan Immobilier).

Chaque page est autonome (données et bibliothèque Leaflet intégrées).
